## Selected Engagements & Impact

<details open>
<summary><b>AI Platform — Elasticsearch, Logstash & Kibana for LLM Inference</b> · Production, Banking Client</summary>
<br/>

Architected an enterprise-grade retrieval platform indexing **10,000+ documents**, using Elasticsearch as the kNN vector store, Logstash for ingestion, and Kibana for observability — fully containerized on Docker and Kubernetes. The pipeline powers an AI chatbot enabling analysts to query ALM, NPA, and treasury knowledge with **sub-3-second semantic retrieval**.

</details>

<details>
<summary><b>Unstructured BFSI Document Pipeline</b> · RAG Infrastructure</summary>
<br/>

Engineered ingestion of unstructured bank documents (PDFs, circulars, treasury reports) through a pipeline of Python parsers → Delta Lake staging → embedding generation → Elasticsearch vector indexing, enabling enterprise-wide semantic search.

</details>

<details>
<summary><b>News & Media Intelligence Datalake</b> · Unstructured RAG Platform</summary>
<br/>

Built an end-to-end intelligence platform unifying News API articles, audio/video transcripts (Whisper), and OCR-extracted text (PaddleOCR) into an air-gap-ready data lake with hybrid BM25 + kNN retrieval, serving a Gemma LLM via Ray Serve with source-attributed, cited responses.

</details>

<details>
<summary><b>Core BFSI Production Pipelines</b> · Murex · Finacle CBS · Bloomberg</summary>
<br/>

Delivered distributed ETL pipelines processing **2TB/day** with a **35% latency reduction** and zero SLA breaches. Built FIXML/SWIFT MT940 parsers handling **8M messages/day at 99.8% parse accuracy**, and a data observability framework across **125+ pipelines** that reduced mean time to detection from hours to **5 minutes**.

</details>

<details>
<summary><b>GuideWire Insurance Data Migration</b> · 8TB PySpark Migration</summary>
<br/>

Achieved a **50% runtime reduction** by resolving partition skew and optimizing PySpark transformations, alongside a **30% compute cost saving** through Z-ordering, partition pruning, and CDC-based incremental loads.

</details>

<details>
<summary><b>AWS Redshift Data Warehouse</b> · 20 BI Workloads</summary>
<br/>

Delivered a **45% query performance improvement** through DISTKEY/SORTKEY redesign and WLM tuning, alongside a rule-based data quality engine enforcing 150+ validation checks integrated into CI/CD.

</details>
